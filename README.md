# 🎓 Student Grade Management Dashboard

A Java-based Student Grade Management Dashboard that helps manage student records, calculate grades, and display overall class performance through a graphical user interface.

## ✨ Features

- Add student records
- Enter Student Name and Student ID
- Enter multiple grades
- Automatically calculate final average
- Display class average
- Identify top performer
- Identify students who need more focus
- Display student records in a table
- Simple and user-friendly GUI

## ⚙️ How It Works

1. Enter the **Student Name**.
2. Enter the **Student ID**.
3. Enter grades separated by commas.
4. Click **Add Student Record**.
5. The system calculates the student's final average.
6. Student information is displayed in the table.
7. The dashboard automatically shows:
   - 📊 Class Average
   - 🏆 Top Performer
   - ⚠️ Student Needing Focus

## 🛠️ Technologies Used

- Java
- Java Swing
- GUI Components
- Event Handling

## 🚀 How to Run

1. Install **JDK** on your system.
2. Open the project in a Java-compatible IDE.
3. Compile `Main.java`.
4. Run the `Main` class.
5. Enter student details and grades to use the dashboard.

## 🎯 Project Purpose

This project demonstrates the use of **Java GUI, event handling, data processing, average calculation, and student performance analysis** in a simple grade management system.
